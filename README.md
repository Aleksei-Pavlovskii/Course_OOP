#  Парсер вакансий с HeadHunter

Проект для поиска и фильтрации вакансий с платформы HeadHunter через API.

## Описание
Этот проект предоставляет инструменты для:

+ Получения вакансий с API HeadHunter

+ Фильтрации вакансий по различным критериям

+ Сохранения результатов в JSON-файл

+ Работы с вакансиями через объектно-ориентированный интерфейс

## Установка и запуск

### Требования

+ Python 3.13 или выше

+ Установленные зависимости из pyproject.toml

### Установка зависимостей
`poetry install`

### Запуск проекта

`python main.py`

## Функциональность

1. Поиск вакансий по ключевым словам

2. Фильтрация по:

+ Городу

+ Ключевым словам в описании

+ Диапазону зарплат

3. Сортировка по уровню зарплаты

4. Сохранение результатов в JSON-файл

5. Просмотр топ-N вакансий

## Классы и модули:

+ `HeadHunterAPI` - работа с API HeadHunter

+ `Vacancy` - представление вакансии с валидацией данных

+ `JSON` - работа с файлами для сохранения/загрузки данных

+ `WorkingWithFiles` - абстрактный класс для работы с файлами

+ `Parser` - абстрактный класс для парсеров

## Использование

После запуска `main.py` программа предложит:

1. Ввести ключевое слово для поиска вакансий

2. Выбрать фильтрацию по городу

3. Указать ключевые слова для фильтрации

4. Задать диапазон зарплат

5. Выбрать количество отображаемых вакансий

6. Решить, очищать ли файл перед сохранением

7. Результаты сохраняются в папку data/vacancies.json
